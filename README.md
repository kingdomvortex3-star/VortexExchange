VortexExchange

Advanced Auction House & Player Trading System

Developed by VortexTeam

VortexExchange is a Minecraft server plugin that combines an Auction House and Player Trading system into one integrated solution. It provides players with a convenient way to trade items and in-game currency while helping server administrators manage transactions and item recovery.

---

Features

Auction House

- Player-to-player item marketplace.
- Create listings using "/ah sell <price>".
- Global announcements when a new item is listed.
- Display seller, item information, quantity, and price.
- Configurable listing limits per player.
- Configurable minimum listing price.
- Configurable listing expiration time.
- Automatic expiration management.
- Return expired items through the Mailbox system.
- Configurable auction tax.

Player Trading

- Send trade requests to other players.
- Accept or deny incoming trade requests.
- GUI-based item trading.
- In-game currency trading.
- Ready confirmation system for both players.
- Configurable maximum trading distance.
- Optional same-world requirement.
- Trade request expiration.
- Trade cooldown.
- Automatic cancellation on damage or disconnection, when enabled.

Mailbox System

- Secure item storage for pending deliveries.
- Automatic item delivery when players join.
- Support for returning expired auction items.
- Support for trade recovery deliveries.
- Persistent mailbox storage.

Trade Recovery

- Persistent storage of active trade information.
- Recovery of unfinished trades after server interruptions.
- Item and currency recovery support.
- Database-backed recovery records.

Language Support

VortexExchange includes two language options:

- English ("en")
- Indonesian ("id")

The language is configured globally through "config.yml".

Database

- SQLite database integration.
- Persistent auction data.
- Persistent active trade records.
- Mailbox data storage.
- Item serialization for persistent storage.

---

Requirements

- Minecraft server: Paper / Purpur
- Server API: 26.3
- Java: 25
- Vault
- A compatible economy provider

---

Installation

1. Download the latest VortexExchange ".jar" release.
2. Place the file into your server's "plugins" folder.
3. Make sure Vault and an economy provider are installed.
4. Restart your Minecraft server.
5. Configure the plugin in "plugins/VortexExchange/config.yml".

---

Commands

Command| Description
"/ah"| Open the Auction House
"/ah sell <price>"| List the item in your hand for sale
"/trade <player>"| Send a trade request
"/trade accept"| Accept a trade request
"/trade deny"| Deny a trade request

Additional trade commands depend on the implemented command configuration.

---

Permissions

Permission| Description| Default
"vortexexchange.use"| Access Auction House and Trading| Everyone
"vortexexchange.admin"| Administrative permission| OP

---

Configuration

Example global language configuration:

settings:
  prefix: "&b&lVortexExchange &8»"
  language: "en"
  debug: false

Available language values:

- "id" — Indonesian
- "en" — English

Auction configuration example:

auction:
  enabled: true
  max-listings-per-player: 10
  listing-duration-hours: 168
  minimum-price: 1
  tax-percent: 0
  expired-items-return: true

The complete configuration is generated by the plugin.
